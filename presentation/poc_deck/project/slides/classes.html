CityVision · Preuve de concept · 14 / 20 · IoU sur les 500 images de validation

(≈ 45 s) Le détail par classe confirme l'hypothèse du plan prévisionnel. Les gains les plus nets sont sur le fond, qui regroupe des éléments très variés (trottoirs, poteaux, clôtures), sur les personnes (+0,042) et sur les panneaux et les vélos (+0,027) : exactement les petits objets où la baseline était faible. Huit classes sur neuf progressent, toutes de façon significative selon le bootstrap. La seule baisse est le ciel, une grande zone homogène que la baseline traitait déjà très bien. Mask2Former est légèrement meilleur qu'EoMT sur les panneaux.
