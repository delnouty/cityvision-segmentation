Le dashboard, déployé sur le cloud

huggingface.co/spaces/DaryaEL/cityvision-poc

  1. Dataset : comptages, exemples par ville et par classe, égalisation, CLAHE, flou
  2. Prediction : choix d'une image et d'un modèle, masque prédit et scores
  3. Model comparison : précision, vitesse, bootstrap, courbes

Accessibilité (WCAG) : textes alternatifs, tableau sous chaque graphique, couleurs lisibles par les daltoniens, commandes au clavier.

CityVision · Preuve de concept · 19 / 20 · Streamlit, 3 modèles exécutés sur CPU dans un Space Hugging Face

(≈ 4 min 30, démo en direct) Avant la soutenance : ouvrir le dashboard quelques minutes à l'avance pour le réveiller (Space gratuit). 1) Page Dataset : montrer les comptages par ville et par classe, la galerie par classe (choisir « bicycle »), puis une transformation : CLAHE avec le curseur, et l'histogramme avant / après. 2) Page Prediction : choisir une image, modèle EoMT, cliquer Predict ; commenter le masque prédit face au vrai masque et le tableau par classe ; puis activer « Compare all models » pour voir les trois côte à côte (≈ 10 s sur CPU). 3) Page Model comparison : le graphique précision / vitesse et les intervalles du bootstrap. Mentionner l'accessibilité : chaque image a un texte alternatif, chaque graphique un tableau. En cas de problème réseau, cette capture sert de secours.
