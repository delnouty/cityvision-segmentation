Limits of the comparison

  • One training run per model. The bootstrap covers which validation images are scored, not the variation from retraining with another seed.
  • The validation set picks the best epoch and is also reported. All three scores are slightly optimistic, by the same mechanism. Cityscapes test labels are not public.
  • Different pretraining. Each model starts from its method's standard checkpoint (ImageNet encoder, ADE20K, COCO panoptic); none had seen Cityscapes.
  • 9 classes at 512×1024. Scores are comparable between these models only, not with published 19-class Cityscapes benchmarks.
  • No data augmentation for any model, so the comparison isolates the architecture. Both transformers overfit moderately (see the train − val gap).
